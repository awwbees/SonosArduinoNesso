# SonosArduinoNesso
project to control sonos speaker grouping via arduino nesso n1, and display current volume

to use, edit the top of the file to add the wifi SSID and password for the network your sonos speakers are on, and change the sonos speaker names to correspond to the speaker names in your home setup

demo: https://www.youtube.com/watch?v=NG-p8ilMaAw
